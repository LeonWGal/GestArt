# Проверка GestArt Ultimate 1.8.0

Дата проверки: 2026-10-24. Среда: Windows 11 x64, MSVC 19.51, Qt 6.8.3,
Release. Профили проверок отделены от рабочего профиля. Этот протокол
описывает локальную проверку; он не подтверждает запуск на всех версиях ОС.

## Автоматические проверки

Пройдены следующие группы CTest:

| Группа | Проверяемое поведение | Результат |
| --- | --- | --- |
| `session_rules` | Таймер, паузы, переходы, лимиты, перерывы, сигналы отсчёта | Пройдена |
| `media_and_storage` | Каталог, декодеры, хранилище, темы, согласованность локалей | Пройдена |
| `online_providers` | Фильтры, HTTPS-хосты, параллельность, повторы, отмена, полные паки, восстановление и продолжение | Пройдена |

В тестах загрузчика проверены все 105 изображений искусственного пака Proko
на трёх страницах, передача анонимной сессии из кэша и продолжение частичного
пака после перезапуска и изменения папки по умолчанию.

## Сквозные сценарии

- Реальный бесплатный пак Proko: сохранены 28 изображений через загрузчик
  с кэшированным каталогом и анонимной сессией.
- Реальная пагинация Proko: список пака из 300 уникальных файлов получен
  по трём страницам. Это проверка списка, а не скачивание всех 300 файлов.
- Встроенный браузер: при уходе курсора верхняя область освобождается;
  при возвращении курсора исходная раскладка восстанавливается.
- Сохранённый сет: запуск через окно настройки выбирает только его,
  даже если в библиотеке присутствует другая коллекция.
- Настройка сохранённого сета помещается в окно 360×440.

## Portable-артефакты

Проверены запуск EXE из папки с пробелами и кириллицей, первое извлечение
встроенного архива, повторный запуск, явный `--data-dir` и возврат кода ошибки
для неизвестного аргумента. Сессия и `--ui-test` проходят через загрузочный EXE.

ZIP проходит проверку CRC всех записей и запускается после распаковки.
Без `--data-dir` EXE создаёт `GestArtUltimate-data` рядом с собой, ZIP — `data`
в корне пакета. Оба варианта проверены с `PATH`, содержащим только системные
каталоги Windows, без Qt SDK и Python в `PATH`.

SHA-256 EXE и ZIP записываются в `SHA256SUMS.txt`. Исходник загрузчика,
скрипт упаковки, лицензии и инструкции включены в исходную поставку.
Готовая поставка содержит все DLL, Qt-плагины, ресурсы WebEngine и лицензии.

## Локализация и документация

Все 22 каталога согласованы по 435 ключам. Проверка локализации проходит;
непереведённые предложения отмечаются предупреждениями и показываются
по-английски. Строгий режим требует перевода таких строк.
README и инструкции описывают опубликованный интерфейс и проверенные
команды сборки и запуска.

## Границы проверки

Локально не запускались Windows 10, Linux и macOS. Для других систем
предусмотрены исходники и CI; результаты конкретного запуска GitHub Actions
следует смотреть в репозитории. Физический прогон мышью, пользовательское
тестирование с новичками и сертификация доступности не проводились.

Публичные API сайтов и доступность паков могут меняться.
Предыдущие результаты находятся в [архиве изменений](../CHANGELOG.md).
