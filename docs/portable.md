# Запустите portable-версию

Portable-сборка предназначена для Windows 10 (1809+) / Windows 11 x64. Она работает без
установки, Qt SDK и Python. Выберите EXE с встроенными файлами или ZIP
с распакованной структурой программы.

## Запустите один EXE

Перед запуском убедитесь, что установлен .NET Framework 4.8 или новее.
Он нужен только загрузочному EXE; приложение внутри написано на C++/Qt.

1. Скачайте `GestArt-Ultimate-1.8.0-windows-x64-portable.exe` со страницы
   [выпуска 1.8.0](https://github.com/LeonWGal/GestArt/releases/tag/ultimate-v1.8.0).
2. Сохраните EXE в папку, в которую можно записывать файлы.
3. Откройте EXE и дождитесь подготовки файлов при первом запуске.

Приложение открывает главную страницу. Настройки, история, кэш браузера и
скачанные сеты находятся в `GestArtUltimate-data` рядом с EXE.
Не удаляйте эту папку при замене версии.

Библиотеки извлекаются в
`%LOCALAPPDATA%/LeonWGal/GestArtUltimate/portable-runtime/ВЕРСИЯ-ХЕШ`.
При повторном запуске используется этот кэш. Архив внутри EXE проверяется
по SHA-256 перед распаковкой; загрузка файлов из интернета не выполняется.
Локальный кэш можно удалить после закрытия всех окон GestArt — следующий
запуск распакует его заново. Данные рядом с EXE при этом сохраняются.

EXE запускается с правами обычного пользователя, не создаёт ярлыки и не
меняет настройки установки Windows.

## Запустите ZIP

1. Скачайте `GestArt-Ultimate-1.8.0-windows-x64-portable.zip` из того же выпуска.
2. Распакуйте архив целиком в доступную для записи папку.
3. Откройте `Start.cmd`.

Настройки и загрузки находятся в `data` внутри распакованной папки.
Файл `portable.flag` включает этот режим при прямом запуске
`bin/GestArtUltimate.exe`. Не удаляйте и не переносите DLL отдельно от программы.
Для ZIP .NET Framework не нужен.

## Обновите версию

1. Закройте GestArt.
2. Скопируйте папку данных в резервное место.
3. Замените EXE или распакуйте ZIP в папку с библиотеками программы,
   сохранив папку данных.
4. Откройте программу и проверьте настройки и **Сохранённые сеты**.

EXE и ZIP используют разные имена папки данных. Для перехода между ними
скопируйте содержимое `GestArtUltimate-data` в `data` или наоборот при
закрытой программе.

Пути к добавленным папкам изображений хранятся как абсолютные. Если после
переноса папки стали недоступны, добавьте их заново. Сеты внутри стандартной
папки загрузки обнаруживаются при открытии **Сохранённых сетов**.

## Укажите отдельный профиль

Для теста или независимого набора настроек передайте `--data-dir`:

```powershell
./GestArt-Ultimate-1.8.0-windows-x64-portable.exe `
  --data-dir D:/GestArt-profile
```

Замените `D:/GestArt-profile` на папку нужного профиля. Этот параметр имеет
приоритет над portable-режимом и не импортирует обычный профиль автоматически.

При запуске исходной сборки без `portable.flag`, `--portable` и `--data-dir`
данные находятся в `%LOCALAPPDATA%/LeonWGal/GestArt Ultimate`.

## Проверьте скачанный файл

Откройте PowerShell в папке скачанного EXE и выполните:

```powershell
Get-FileHash ./GestArt-Ultimate-1.8.0-windows-x64-portable.exe `
  -Algorithm SHA256
```

Сравните поле `Hash` со строкой этого файла в `SHA256SUMS.txt` из выпуска.
Для начала практики см. [выбор сайтов и сохранённых сетов](online-sources.md).

Требования платформы приведены в [документации Qt 6.8](https://doc.qt.io/qt-6.8/supported-platforms.html#windows).
Проверку и установку .NET Framework см. в [инструкции Microsoft](https://learn.microsoft.com/en-us/dotnet/framework/install/on-windows-and-server).
