## Что можно очистить отдельно

- **Старый `build`: 65,70 МиБ.** Он не используется `Start.cmd`: запускается `release/bin/GestArtUltimate.exe`. Устаревшие промежуточные объекты могут содержать прежние ресурсы; они не входят в обновлённый EXE.
- **`tools/localization/node_modules`: 78,07 МиБ.** Удаление повлияет только на инструменты перевода до повторной установки зависимостей.
- **Корневые `*.log`: около 78 КиБ.** Журналы сборок и тестов, приложению не нужны.
- **`tools/localization/drafts`: 0,30 МиБ.** Рабочие копии переводов. Инструмент умеет восстанавливать отсутствующие черновики из опубликованных каталогов. Редакторские отчёты и журналы переводчика также можно архивировать после выпуска.
- **Qt SDK: 2,30 ГиБ.** Его можно вынести из папки программы в общий каталог SDK и перенастроить сборку. Удалять сейчас нельзя без потери возможности сборки в текущем окружении. Крупнейшие библиотеки QmlDom/QmlLS нужны инструментам Qt; выборочное удаление `.lib` может повредить SDK.
- **Резервные копии:** 36,65 МиБ до этого обновления; обновление 1.5.3 добавляет резервную копию. Это данные для отката, а не активные языки приложения.

Кандидаты с небольшими последствиями — старый `build`, `node_modules` и корневые журналы: примерно **144 МиБ**. В этой задаче они проанализированы и оставлены, поскольку запрос на удаление относился к старым языкам.

## Что не считать старыми переводами программы

`release/translations/qt_*.qm` (6,74 МиБ) — стандартные ресурсы самого Qt, автоматически добавленные развёртыванием. Это не удаляемые 100 JSON-словарей GestArt. При отдельной оптимизации дистрибутива можно настроить их состав и проверить системные диалоги. Не следует удалять DLL, плагины, QML-модули, шрифты и лицензии по одному признаку «много файлов».

`tools/localization/.env` — локальная конфигурация переводчика с секретом. Она не входит в дистрибутив и не относится к мусору. Содержимое при анализе не читалось и в отчёт не включалось.

Пользовательские история и настройки находятся вне папки проекта: `%LOCALAPPDATA%/GestArt/GestArt Ultimate`. Очистка переводов их не удаляет.

## Результат очистки языков

Из активных ресурсов удалены `assets/locales` (100 JSON), `assets/locales-extra` (2 JSON) и устаревший `legacy-sha256.json`. Объём удалённых словарей — 760 510 байт. Новые 22 JSON сохранены без изменения содержимого, реестр языков сокращён до них. Загрузчик больше не обращается к старым папкам. Если в профиле выбран снятый с поддержки язык, сохраняется русский язык вместо недействительного кода.

Перед установкой старые словари архивируются вместе с резервной копией выпуска в `.backups`. Они остаются только для отката и не включаются в ресурсы новой программы. Исторические отчёты о версии 1.5.2 сохранены как описание прежнего выпуска.
