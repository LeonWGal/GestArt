# GestArt Ultimate 1.8.0

Этот выпуск объединяет загрузку референсов, постоянный список сохранённых
сетов и переносные Windows-сборки. Для начала работы см. [README](../README.md).

## Скачивание и сессии

Во вкладке **Скачать с сайта** выберите сайт, сеты и объём. Дополнительные
фильтры и выбор папки находятся в **Фильтры и папка сохранения**. После
скачивания откройте **Сохранённые сеты**, настройте таймер и начните сессию.
Другие коллекции не включаются.

**Скачать весь пак** сохраняет все доступные изображения Quickposes, Proko
или Pose Library. Для SketchDaily задайте количество случайных изображений.
Полные паки Proko обрабатываются постранично. Отмена сохраняет готовые файлы;
частичный пак можно продолжить после перезапуска.

## Просмотр сайта

При уходе курсора верхняя панель не только скрывается, но и перестаёт
занимать место. Область сайта расширяется до верхнего края и восстанавливается
при возвращении курсора. Настройки и таймер сайта продолжают работать.

## Portable

EXE включает ZIP с программой и библиотеками, проверяет его SHA-256 и
распаковывает в локальный кэш. Пользовательские данные находятся рядом с EXE.
ZIP хранит данные в своей папке `data`; режим задаёт файл `portable.flag`.
Подробности и обновление см. в [инструкции portable](portable.md).

## Проверка

Проверены CTest, полный бесплатный пак Proko из 28 изображений, реальная
пагинация списка из 300 файлов, восстановление сетов и запуск только выбранного
сета при наличии других коллекций. Проверки используют отдельные профили.
Результаты сборки portable и её запуска см. в [протоколе выпуска](verification.md).
