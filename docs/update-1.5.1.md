# Исправления управления — 1.5.1

Навигация сессии: назад, пауза/продолжение, пропустить, вперёд. Все четыре кнопки имеют прозрачный фон; остаются реакции на наведение, нажатие и клавиатурный фокус. Сброс изображения с предоставленной иконкой Restore возвращён после сетки, перед вписыванием.

Таймер всегда находится в 16 px от верхнего края. Его горизонтальная позиция соответствует настройкам при любой ширине окна. Если таймер пересекается с верхними панелями, ниже перемещаются эти панели. Проверены левая, центральная и правая позиции при ширине 360 и 800 px: шесть вариантов без пересечений.

«Вписать» заметно подсвечено акцентным цветом, когда масштаб равен вписанному и изображение не сдвинуто. Масштабирование и перемещение снимают подсветку. Нажатие кнопки всегда возвращает к вписыванию; Ctrl+1 отдельно включает масштаб 100%.

Хоткеи сессии действуют только на её рабочем экране. Они отключены во время ввода текста, в настройках, меню, предпросмотре и на экране итогов. Escape закрывает открытые панели, результаты или полноэкранный режим по контексту. При просмотре коллекции или истории управление изображением сессии недоступно.

| Действие | Клавиши |
| --- | --- |
| Пауза / продолжить | Space |
| Предыдущее / следующее | ← / → |
| Пропустить без зачёта этюда | S |
| Чёрно-белый режим | B |
| Горизонтальное / вертикальное отражение | H / V |
| Поворот на 90° | R |
| Сетка | G |
| Сбросить изображение и масштаб, сохранив направляющую сетку | Backspace |
| Вписать | Ctrl+0 |
| Масштаб 100% | Ctrl+1 |
| Увеличить | Ctrl++ или Ctrl+= |
| Уменьшить | Ctrl+- |
| Копировать изображение | Ctrl+C или C |
| Открыть оригинал внешней программой | O |
| Переместить оригинал в корзину | Delete |
| Закрепить поверх окон | A |
| Показать / скрыть таймер | T |
| Полный экран | F11 |
| Настройки | Ctrl+, |
| Навигация приложения | Ctrl+B |

Предпросмотр использует собственные ←/→, Ctrl+0 и сочетания увеличения/уменьшения. Закрытие предпросмотра возвращает на исходную страницу.

Проверка `--controls-test` использует отдельный профиль и активное окно Qt. Она проверяет порядок и прозрачность навигации, исходную подсветку вписывания, её отключение при перемещении, Ctrl+0, B/H/V/R/G, Backspace, Ctrl+=, Space, Ctrl+, блокировку команды B в настройках и шесть вариантов расположения таймера. Остальные хоткеи проверены по привязкам к командам. Копирование не запускалось тестом, чтобы не менять пользовательский буфер обмена. Дополнительно пройдены проверки завершения сессии и независимого предпросмотра; проверены снимки минимального и обычного окна.
