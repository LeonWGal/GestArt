# GestArt Ultimate 1.7.0

## Два режима онлайн-референсов

**Сайты** открывает Quickposes, Proko, Pose Library и SketchDaily внутри GestArt. Сохраняются настройки и входы в аккаунты; доступны собственные таймеры сайтов. Навигация GestArt не перехватывает клавиатуру сайта. Браузер создаётся при первом открытии сайта.

**Загрузчик** позволяет выбрать несколько наборов, количество изображений на набор и папку сохранения. Очередь объединяет наборы разных сайтов; отдельное сохранение группирует каждый набор в своей папке. У скачанных наборов есть кнопки запуска сессии GestArt и открытия папки.

## Проверки

Три группы CTest прошли; тесты онлайн-части содержат 12 сценариев. Все четыре сайта загрузились во встроенном браузере. Проверена автономная сборка без SDK: отображение Quickposes, загрузка шести изображений из трёх наборов в три папки и запуск сессии из нужной папки. Проверены кнопки и горячие клавиши, отдельный предпросмотр коллекций/истории и узкий интерфейс 360×440.

26 новых строк переведены через lobe-i18n/Gemini на 20 дополнительных языков. Во всех 22 каталогах по 364 ключа; структурная проверка прошла без предупреждений.

Очередь не восстанавливается после выхода; скачанные файлы, коллекции и выбранная папка остаются. Сайты требуют интернета и могут менять свои функции. macOS/Linux в этом окружении не собраны.
