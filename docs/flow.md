# Выберите способ практики

GestArt поддерживает локальные изображения, встроенные сайты и скачанные
сеты. Выберите путь по тому, какой таймер и какие файлы вам нужны.

## Используйте свою папку

На главной добавьте папку, выберите время и количество рисунков, затем
нажмите **Начать сессию**. Выбор папок относится к следующей сессии.
Локальные изображения не загружаются в интернет.

## Скачайте референсы для GestArt

Путь: **Скачать референсы → Скачать с сайта → сайт → сеты → объём → скачать**.
После завершения открываются **Сохранённые сеты**. Выберите **Настроить сессию**,
задайте время и нажмите **Начать сессию**. Используется только этот сет.

Сохранённые сеты доступны на главной и в боковой панели после перезапуска.
Для одного сета можно сразу начать сессию после скачивания. Прогресс
остаётся видимым при прокрутке; остановка сохраняет готовые изображения.
Частичный сет можно продолжить.

## Используйте таймер сайта

Путь: **Онлайн-просмотр → Открыть сайт**. Встроенный браузер сохраняет
настройки и аккаунт самого сайта. При уходе курсора панель скрывается вместе
с занимаемой областью; изображение использует освободившееся место.
Для перехода к таймеру GestArt выберите **Скачать референсы**.

## Продолжите практику

В сессии пробел управляет паузой, стрелки переключают референсы, S пропускает
изображение без отметки завершения. Открытие настроек или другой страницы
приостанавливает локальную сессию. История и статистика учитывают завершённые
этюды и исключают паузы.

После завершения откройте результаты, повторите сессию или выберите другой
сет. Смотрите [подробности онлайн-сценария](online-sources.md) и
[управление сессией](interface.md).
