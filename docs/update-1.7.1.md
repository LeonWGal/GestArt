# GestArt Ultimate 1.7.1

Онлайн-просмотр и скачивание разделены: у них отдельные точки входа на главной и в коллекциях. Страница онлайн-просмотра запускает сайт с его настройками. Загрузчик содержит источник, наборы, фильтры, сохранение и очередь.

В узком или низком окне панель сайта сокращается до возврата, выбора сайта и меню. Адрес и дополнительные кнопки скрываются; команды обновления и загрузчика доступны в меню.

Для Quickposes добавлены пол и одежда; для SketchDaily — пол, одежда, тип позы и ракурс. У Proko и Pose Library используются реальные доступные наборы. Фильтры сохраняются в заданиях очереди и в метаданных скачанных изображений. Отдельные папки учитывают сочетание фильтров.

Проверка исходных протоколов: Quickposes вернул 400 референсов для женщин в одежде; ответ SketchDaily подтвердил Gender=Female, Clothing=true, PoseType=Stationary, ViewAngle=Front. Тесты проверяют формирование параметров, отбрасывание неизвестных значений и отдельные задания для разных фильтров. Все три группы CTest прошли.

22 новые строки переведены через lobe-i18n/Gemini на 20 языков; название заднего ракурса уточнено отдельно, чтобы не смешивать его с командой навигации «Назад». Во всех 22 каталогах по 387 ключей.
