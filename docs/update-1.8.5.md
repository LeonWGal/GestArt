# GestArt Ultimate 1.8.5

Обновление браузера для просмотра YouTube и работы с референсами.

### Added

- YouTube во встроенном браузере: поиск, открытие ссылок, канал GES DRAW PARTY и два плейлиста с названиями и превью.
- Видео во всё окно, выход по Esc и кнопка закрепления поверх других окон.
- Карточка возврата на текущую страницу; последний адрес каждого сайта сохраняется на время работы приложения.

### Changed

- Панель браузера открывается кнопкой с ползунками. Поиск доступен по Ctrl+L, дополнительные действия — через отдельное меню «…».
- Минимальный размер окна браузера — 280×160. Панель остаётся однострочной и закрывается при изменении размера.
- Интерфейс использует шрифт Geist и обновлённые элементы управления. Прежние цветовые акценты сопоставляются с палитрой Lobe.

### Fixed

- Скрытие панели больше не меняет размеры страницы и не подменяет содержимое сайта изображением.
- Кнопка открытия панели и сама панель не растягиваются при переходе между обычным просмотром и видео во всё окно.
- Закрытие меню при изменении размера не возвращает фокус в скрытую строку поиска.

## Обновление

Закройте GestArt перед заменой файлов. Для portable EXE сохраните папку `GestArtUltimate-data` рядом с программой; для ZIP сохраните папку `data`. Распакуйте ZIP целиком и запустите `Start.cmd`, либо откройте portable EXE. Пользовательские данные не входят в архивы выпуска.

## Downloads

- **Portable EXE** — приложение со встроенными библиотеками, установка не требуется.
- **Portable ZIP** — полная папка приложения для распаковки.
- **SHA256SUMS.txt** — контрольные суммы обоих файлов.
