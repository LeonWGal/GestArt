# Перевод нового интерфейса

Этот инструмент обновляет только `assets/locales-v2`. Реестр `assets/languages.json` содержит только 22 актуальных языка. Старые каталоги удалены.

Настроены 20 дополнительных языков: de, fr, es, pt-BR, it, pl, uk, tr, zh-CN, zh-TW, ja, ko, ar, id, vi, th, nl, cs, hu, ro. Русский и английский используют отдельные исходные словари нового слоя. В приложении доступны только эти 22 языка.

## Подготовка

1. Установите Node.js версии 18 или выше.
2. Откройте терминал в `tools/localization` и выполните `npm ci --ignore-scripts`.
3. Создайте `.env` по образцу `.env.example`. Укажите ключ Gemini в `OPENAI_API_KEY`. Реальный ключ хранится только локально; `.env`, временные ответы и зависимости исключены из Git.
4. При необходимости измените `GEMINI_MODEL`. В проверенном запуске использовалась `gemini-3.5-flash-lite`.

## Обновление

Добавьте исходные строки в `assets/locales-v2/en.json`. Обновите терминологию и пояснения в `context.txt`, затем выполните:

```sh
npm run translate
```

Команда запускает закреплённый `@lobehub/i18n-cli@1.27.0`, дополняет недостающие строки в `drafts`, проверяет результат и переносит проверенные файлы в `assets/locales-v2`. Прежние строки в готовых файлах повторно не запрашиваются. Для исправления конкретного перевода удалите его ключ из соответствующего файла `drafts` и повторите команду.

Проверка опубликованных каталогов без запросов к API:

```sh
npm run validate
```

Дополнительная языковая диагностика:

```sh
npm run lint
```

Языковой детектор ELD часто считает короткие слова, названия камней, единицы и похожие индонезийские/малайские фразы другим языком. Его отчёт предназначен для редактора; он не заменяет проверку носителем языка. Структурный валидатор отдельно проверяет ключи, типы значений, пропуски, подстановки, переносы строк и оставшиеся английские предложения.

## Gemini и совместимость CLI

`run.mjs` использует локальный HTTP-адаптер только на `127.0.0.1` со случайным токеном на каждый запуск. Адаптер отправляет запросы на официальный OpenAI-совместимый endpoint Gemini. Настоящий ключ передаётся только Google; дочерний CLI получает временный локальный токен.

В конфигурации CLI указано `gpt-4.1` как идентификатор для его таблицы размеров контекста: закреплённая версия CLI не содержит Gemini в этой таблице. Адаптер заменяет это имя на фактическую модель Gemini из `.env`. Это предотвращает дробление словаря на сотни запросов при неизвестном для CLI имени модели. Сам пакет CLI не изменён.

В API передаются исходные подписи интерфейса и глоссарий. Изображения, пользовательская история и настройки профиля в переводе не участвуют. Ключ и Node.js не требуются пользователю собранного приложения.

## Проверки перед выпуском

- Все 20 словарей должны содержать полный набор исходных ключей.
- Реестр должен совпадать с 22 опубликованными каталогами.
- Выполните тесты CMake/CTest, включая категории числительных и загрузку каталогов.
- Проверьте минимальное окно, длинные подписи, арабское направление текста и восточноазиатские шрифты.
- Перед публичным коммерческим выпуском проведите контекстную вычитку носителями языков. Текущий результат — машинный перевод с редакторской проверкой терминологии и техническими тестами.

## Английский fallback в 1.8.0

Для строк без перевода приложение использует английский текст.
`node validate.mjs` сообщает такие строки как предупреждения, сохраняя
проверку ключей и подстановок. `node validate.mjs --strict` и `--promote`
считают непереведённые предложения ошибками. Для запуска приложения
ключ API не нужен; `.env` и журналы не включаются в репозиторий.
