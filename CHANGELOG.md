# История изменений

Изменения выпусков GestArt Ultimate сгруппированы по их влиянию на работу
с референсами. Прежняя версия GestArt находится в ветке `old`.

## Unreleased

Нет опубликованных изменений после 1.8.0.

## [1.8.0 — 2026-10-24](https://github.com/LeonWGal/GestArt/releases/tag/ultimate-v1.8.0)

### Added

- Portable EXE со встроенными библиотеками и portable ZIP для Windows x64.
- Хранение данных рядом с portable-сборкой и явный параметр `--portable`.
- Вкладка **Сохранённые сеты**, доступная после перезапуска.
- Настройка таймера перед запуском сессии из одного сохранённого сета.
- **Скачать весь пак** для Quickposes, Proko и Pose Library.
- Поиск сетов, превью сайтов и сетов, продолжение частичной загрузки.

### Changed

- Скачивание проходит через выбор сайта, сетов и объёма с одной основной кнопкой.
- Каждый скачанный сет сохраняется в отдельную папку.
- Изображения скачиваются параллельно, с ограничением числа запросов,
  повторными попытками и кэшем каталога.
- Прогресс загрузки остаётся виден при прокрутке.

### Fixed

- Верхняя панель браузера при скрытии освобождает место изображению.
- Запуск сохранённого сета исключает другие выбранные коллекции.
- Кэшированный каталог Proko передаёт загрузчику анонимную сессию сайта.
- Полный пак Proko загружается со всех страниц, включая паки больше 100 файлов.
- Обновление `sources.json` после продолжения загрузки не блокируется открытым
  на чтение файлом в Windows.
- Для медленного API Pose Library предусмотрено отдельное время ожидания.
