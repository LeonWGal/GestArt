# Внесите изменения в GestArt Ultimate

Разработка версии C++/Qt ведётся в ветке `ultimate`. Эта инструкция
предназначена для разработчиков, которые хотят собрать программу и проверить
свои изменения. Начните с [подготовки сборки](docs/build.md).

## Подготовьте изменение

1. Создайте рабочую ветку от `ultimate`.
2. Внесите изменение в `src`, `qml`, `assets` или инструменты сборки.
3. Запустите сборку и CTest по инструкции разработчика.
4. Для изменения интерфейса проверьте обычное окно и размер 360×440.
5. Опишите поведение и проверку в pull request.

Не добавляйте Qt SDK, каталоги `build`, `release`, `dist`, резервные копии,
загрузки референсов, пользовательские профили, `node_modules` и `.env`.
Для онлайн-проверок используйте отдельный `--data-dir`, чтобы не менять
рабочую историю и коллекции.

## Проверьте локализацию

Изменяйте ключи в `assets/locales-v2`. Все 22 каталога должны содержать одинаковые
ключи; CTest проверяет их согласованность. Для отсутствующего перевода допустим
английский текст без выдуманного машинного перевода.
Инструменты перевода описаны в [tools/localization](tools/localization/README.md).
Ключ API используется только локальным инструментом и не нужен приложению.

## Подготовьте выпуск

Согласуйте версию в `CMakeLists.txt`, `src/main.cpp` и `assets/version.rc`.
Обновите `CHANGELOG.md`, README и инструкции, затем соберите portable-артефакты
по [инструкции сборки](docs/build.md#соберите-portable-exe-и-zip).
Публикуйте готовые бинарные файлы в GitHub Releases, а исходники — в ветке.
